# NUTRIO

**NUTRIO** — дневник питания для ежедневного учёта калорий, белков, жиров и углеводов (КБЖУ). Добавляй продукты с указанием веса и состояния приготовления, задавай личные дневные цели и смотри, сколько уже съедено и сколько осталось до нормы.

- **Демо:** https://olegterekhov.github.io/RecipePro/
- **Формат:** адаптивное веб-приложение / PWA для телефона и компьютера.
- **Технологии:** HTML, CSS, Vanilla JavaScript, Supabase Auth и PostgreSQL.

## Основные возможности

- **Дневник питания:** запись продуктов по датам с указанием веса, состояния приготовления и приёма пищи.
- **Расчёт КБЖУ:** автоматический подсчёт калорий, белков, жиров и углеводов для добавленных продуктов и блюд.
- **Личные цели:** настройка дневной нормы калорий и КБЖУ, просмотр прогресса и остатка до цели.
- **История питания:** календарь для просмотра записей за предыдущие дни.
- **Собственные блюда:** сохранение пользовательских блюд для повторного использования.
- **Синхронизация:** при входе в аккаунт данные дневника и целей могут синхронизироваться между устройствами через Supabase.
- **PWA:** приложение можно установить на совместимые устройства; предусмотрены локальное хранение и офлайн-кэш.

## Технологии и структура

- **JS/products.js, JS/product-resolver.js** — каталог продуктов и сопоставление названий.
- **JS/nutrition-engine.js** — расчёт пищевой ценности и КБЖУ.
- **JS/cloud-sync.js** — авторизация и облачная синхронизация через Supabase.
- **sw.js, manifest.webmanifest** — PWA и офлайн-кэш.
- **supabase/schema.sql, supabase/migrations/** — схема базы данных и миграции.
- GitHub Actions — автоматические проверки проекта и сборка Android-пакета.

## Хранение данных и безопасность

Данные аккаунта хранятся в таблицах Supabase и защищаются политиками Row Level Security (RLS). В клиентском приложении следует использовать только публичный publishable/anon-ключ. **Нельзя добавлять в публичный репозиторий service_role или secret key.**

Инструкции по настройке облачной части находятся в [docs/CLOUD_BACKEND.md](docs/CLOUD_BACKEND.md).

## Важно

NUTRIO предназначен для ведения дневника питания и ориентировочного расчёта пищевой ценности. Точность зависит от данных о продукте, его бренда, веса и способа приготовления. Приложение не заменяет консультацию врача или диетолога.
