# RecipePro

**RecipePro** — локально-ориентированный помощник по готовке: подбирает блюда из имеющихся продуктов, рассчитывает КБЖУ и помогает спланировать питание и покупки.

- **Демо:** https://olegterekhov.github.io/RecipePro/
- **Формат:** адаптивное веб-приложение / PWA для установки на телефон и компьютер.
- **Стек:** HTML, CSS, Vanilla JavaScript, Supabase Auth и Postgres.

## Возможности

- Поиск и подбор рецептов по продуктам, фильтры по времени и типу питания.
- Создание, сохранение и удаление собственных рецептов.
- Избранное и история последних просмотренных рецептов.
- Калькулятор КБЖУ с учётом состояния продукта и масла при жарке.
- Умный генератор рецептов на основе локальных кулинарных правил — работает без внешнего AI API.
- План питания на семь дней.
- Список покупок из запланированных блюд: объединение ингредиентов, отметки купленного, ручное добавление и копирование списка.
- PWA с офлайн-кэшем и локальным хранением данных.
- Облачная синхронизация собственных рецептов, избранного, плана питания, списка покупок и истории между устройствами после входа в аккаунт.

## Архитектура

- `JS/products.js`, `JS/product-resolver.js` — каталог продуктов и сопоставление названий.
- `JS/recipe-engine.js`, `JS/recipe-builder.js`, `JS/recommendation-engine.js` — логика построения и ранжирования рецептов.
- `JS/nutrition-engine.js`, `JS/nutrition.js` — расчёт пищевой ценности.
- `JS/ai-generator.js` — локальная генерация и адаптация рецептов без обращения к внешней модели.
- `JS/meal-planner.js` — недельный план, список покупок и история.
- `JS/cloud-sync.js` — вход и синхронизация с Supabase.
- `sw.js`, `manifest.webmanifest` — установка и офлайн-режим.
- `supabase/schema.sql`, `supabase/migrations/` — схема базы данных и изменения.

## Облачные данные и безопасность

Данные аккаунта хранятся в `public.recipepro_user_data`. Доступ к строке ограничен политиками Row Level Security (RLS) по `auth.uid()`. В клиентском приложении разрешено использовать только publishable/anon key. **Нельзя помещать в публичный репозиторий `service_role` или secret key.**

Инструкции по настройке находятся в [docs/CLOUD_BACKEND.md](docs/CLOUD_BACKEND.md).

## Проверки

GitHub Actions проверяет синтаксис JavaScript, наличие PWA-файлов и путей к ресурсам, а также запускает тесты расчёта питания, рекомендаций, сопоставления продуктов и интеграции планировщика.

## Текущая граница AI-функций

Генератор рецептов работает локально на правилах и может работать офлайн. Внешняя языковая модель (LLM) пока не подключена; для настоящего AI-чата потребуется серверная интеграция и ключ выбранного провайдера, хранящийся только в серверных секретах.
